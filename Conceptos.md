## Hacer un Fork de un repositorio

Primero entro en el repositorio de mi compañero en GitHub y pulso Fork para crear una copia en mi cuenta.

Después clono el repositorio en mi ordenador con git clone y entro en la carpeta. Creo una rama nueva para hacer mis cambios y, cuando termino, hago un commit.

Luego subo la rama a GitHub con git push y creo un Pull Request hacia el repositorio de mi compañero para que pueda revisar y aceptar mis cambios.
